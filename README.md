# Shell Emulator

## 1. Общее описание

Эмулятор командной оболочки UNIX-подобной ОС (вариант №4).
Реализован этап 1 — REPL: пользователь вводит команды в
графическом окне, эмулятор разбирает ввод и выводит результат.

Язык реализации: Python 3.
Интерфейс: tkinter (стандартная библиотека).

## 2. Функции и настройки

### Модули

| Файл | Назначение |
|------|------------|
| `src/main.py` | Точка входа, запуск приложения |
| `src/gui.py` | Графический интерфейс (окно, ввод, вывод) |
| `src/parser.py` | Парсер: разбивает строку на команду и аргументы |
| `src/commands.py` | Обработка команд `ls`, `cd`, `exit` |

### Настройки

| Параметр | Значение | Описание |
|----------|----------|----------|
| `VFS_NAME` | `stub-vfs` | Имя VFS, отображается в заголовке окна |
| `USER_PROMPT` | `stub-vfs$ ` | Приглашение командной строки в GUI |

### Команды эмулятора

| Команда | Описание |
|---------|----------|
| `ls [аргументы]` | Заглушка: выводит имя команды и аргументы |
| `cd [аргументы]` | Заглушка: выводит имя команды и аргументы |
| `exit` | Завершение работы приложения |

Неизвестная команда выводит сообщение об ошибке:
`<команда>: command not found`.

## 3. Сборка и запуск

Сборка не требуется — проект использует только стандартную
библиотеку Python.

### Запуск приложения

```bash
./run.sh
```

или

```bash
python3 -m src.main
```

### Запуск тестов

```bash
python3 -m unittest discover -s tests -v
```

## 4. Примеры использования

После запуска введите команду в нижнее поле и нажмите Enter.

```
stub-vfs$ ls
ls

stub-vfs$ ls -l /home
ls: -l /home

stub-vfs$ cd /tmp
cd: /tmp

stub-vfs$ cd
cd

stub-vfs$ exit
```

Окно закрывается.

### Обработка ошибок

```
stub-vfs$ unknown
unknown: command not found
```

Пустая строка игнорируется (ошибка не выводится).
